# Contacts that are easy to browse

The user requests all contacts in a friendly searchable list and an active contact view. Existing Oracle contacts are empty; a read-only legacy scan finds one saved phone contact. The user confirmed both saved leads and available linked WhatsApp contacts. The default workspace imports saved leads once; separate workspaces retain explicit import. WhatsApp contact events add directory entries inactive, never message content. Explicit deletion suppresses automatic rediscovery; operator import remains available.

Keep a visible search field on Contacts and WhatsApp, filter results as typing changes, accept formatted phone-number searches, and show counts/clear controls. Clicking or arrow-selecting a result updates a persistent contact preview. Include phone numbers and access status. Keep a preview available at 80×24. Preview overview, conversation and permanent memory without turning selection into consent or message sending. Preserve selection by contact ID across refresh and show clear empty/no-match states.

Keyboard: / or Ctrl+F focuses search; text entry consumes normal typing; Enter/Down/Tab returns to results; Escape leaves search; Clear resets filters. Mouse: search caret, result rows, visible actions, preview tabs and wheel scrolling. Existing action menu and exact-send review remain available.

Contacts from external sources must remain separate from outreach permission. Never expand message monitoring to unapproved contacts while improving directory discovery. Do not promise WhatsApp supplies the entire phone address book; any sync must use actual available metadata, exact phone identities and truthful source/status messages.

WhatsApp contact-state synchronization is requested separately after app-state keys are available, because skipped message-history sync can otherwise omit the initial app-state fetch. A Refresh WhatsApp control requests incremental contact-state updates using the installed Baileys collection list; it does not reset authentication versions or request message-history bodies. Full phone-address-book coverage cannot be guaranteed by WhatsApp.
