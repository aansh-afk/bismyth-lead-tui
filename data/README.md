# India location data

India-only state/UT and city names extracted from @countrystatecity/countries 1.0.9 (dr5hn CountryStateCity database).

Source: https://github.com/dr5hn/countries-states-cities-database
Package: https://www.npmjs.com/package/@countrystatecity/countries
